# 第四章：阵总线与六面处理器

## 1. 阵总线是什么

阵总线把最多六个面处理器集中在一个无碰撞方块位置。每个面拥有自己的阵类型、存储、加工状态和外部能力访问。渲染和选面使用厚度为 1/16 方块的表面薄片。

阵总线本体不可碰撞，空面也不会提供处理器。玩家瞄准时，代码会对已安装的面进行视线检测，尽量避免边缘点击落到错误方向。

## 2. 放置后的默认状态

放置阵总线时，服务端会自动在 `DOWN` 面安装不稳定筛分阵。它不是空白六面容器。因此第一次规划总线时，应先把下表面视为已占用。

拆除阵总线后，方块自身按正常规则掉落，六面处理器中的物品由总线额外收集并生成掉落。不要用世界重载行为代替正常拆除测试。

## 3. 安装处理器

手持任意动态注册的阵方块右击阵总线，程序读取该方块 ID 对应的阵类型，并把它安装到命中的表面。完成后会刷新方块能力。

目标面通常由视线命中决定。副手持带 `side` 自定义数据的示例物品时，可以覆盖目标面。示例物品右击空气会按上、下、北、南、西、东循环方向并发送英文调试消息。

**限制：**示例物品属于开发工具，相关分支还存在一个不带 `_zhen` 后缀的筛分类型查询，和正式注册 ID 不一致，因此不应把“示例物品直接右击总线安装筛分阵”作为可靠玩家流程。更可靠的方法是主手持实际阵方块安装。

## 4. 每个面的 IO

普通阵处理器默认具有：

- 物品槽 0：输入。
- 物品槽 1：输出。
- 六个方向：同时暴露物品输入区和输出区。
- 凝露类处理器：额外具有 1000 mB 流体输出槽。

阵总线对外暴露能力时，会先确定被查询方向对应的面处理器，再将允许区域与输入/输出槽求交集。自动化设备连接某一侧，只访问该侧处理器，不会自动访问其他五面。

## 5. 总线自动化步骤

1. 为每个方向安排一个功能，记录面朝向。
2. 用实际阵方块逐面安装，安装后用 Jade 或一次小批量配方验证类型。
3. 将输入管线连接到该面；默认情况下同一面也允许抽取输出。
4. 对凝露面连接流体抽取设备，避免 1000 mB 内槽填满。
5. 对带 `drop_output` 的配方额外布置实体收集方案。
6. 最后进行多面并行压力测试，确认每面材料没有接错。

## 6. Jade 信息

安装 Jade 时，瞄准已安装表面可将方块名称替换为对应阵名，并展示物品、流体和能量信息。能量文本使用 `当前值 / 容量 FE`。

Jade 是可选依赖。没有 Jade 不会停止加工，但玩家缺少直观诊断信息。当前中文语言文件包含阵总线及其物品、流体插件名称。

## 7. 限制与排错

- 若管道完全无法连接，先确认连接的是已安装处理器的面，而不是空面。
- 若输入进入错误功能，重新核对物理方向和视线选面，不要只依据渲染颜色猜测。
- 若加工完成但看不到随机产物，检查世界掉落方向和实体收集范围。
- 总线没有统一共享库存；六面存储相互独立，不能依赖总线内部自动搬运。
- 当前源码没有面处理器的常规 GUI 配置流程，复杂诊断依赖 Jade、外部传输设备或开发调试。
