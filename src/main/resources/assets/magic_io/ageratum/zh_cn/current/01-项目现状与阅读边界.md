# 第一章：项目现状与阅读边界

## 1. 教程依据

本教程只描述当前工作区源码已经注册、加载或执行的行为。设计稿中的世界观、科技树和未来物品不自动视为可用内容。判断优先级如下：

1. Java 注册与运行逻辑。
2. `src/main/resources` 中随模组装载的数据。
3. 本地化文本和可选兼容代码。
4. 规划文档仅用于解释设计意图，不用于证明功能已经实现。

因此，“存在名称”“存在规划”“存在类”都不等于玩家流程已经闭环。文中使用三类标记：

- **已实现**：当前源码有完整注册或执行入口。
- **受限实现**：主体可运行，但交互、数据或展示存在明确边界。
- **占位/调试**：源码保留了示例、测试或尚未闭环的入口，不应当作正式玩法承诺。

## 2. 当前技术基线

| 项目 | 当前值 | 影响 |
| --- | --- | --- |
| Minecraft | 26.1.2 | 教程中的类名和资源格式仅针对此版本 |
| NeoForge | 26.1.2.41-beta | 使用 NeoForge 注册表、能力与事件总线 |

| Jade | 仅编译期可选 | 没有 Jade 时不影响核心加工，但没有对应信息覆盖层 |

## 3. 当前内容边界

当前可明确确认的独立物品只有煤焦和示例物品；核心内容主要由动态注册的阵方块、阵总线和网格面板构成。阵功能会按“引入等级”向更高等级自动展开，因此注册方块数量大于功能定义数量。

六个等级依次为：不稳定 0、稳定 10、稳固 20、充盈 30、古朴 40、远古 50。当前不是 LV/MV/HV/EV/IV/MAX 的代码命名体系，教程以实际中文本地化名称为准。

## 4. 玩家可见入口

- 创造模式标签页会列出示例物品、全部动态阵方块、阵总线和网格面板。
- 单独放置阵方块后，服务端方块实体会执行配方加工。
- 放置阵总线后，其下表面默认安装一个不稳定筛分阵处理器。
- 手持其他阵方块右击阵总线，可把对应处理器安装到目标表面。
- JEI 存在时可显示阵配方；Jade 存在时可显示阵总线表面的阵名、物品、流体和能量信息。

## 5. 必须提前知道的限制

1. 当前没有生存模式合成链能够保证取得全部核心方块；教程中的完整体验更适合作为创造模式或数据包开发验证。
2. `example_item`、示例方块名称、示例配置项和部分英文系统消息仍属于开发痕迹。
3. 独立阵方块没有常规菜单界面，主要通过方块能力与相邻自动化设备交换资源。
4. 大部分阵功能只有通用配方处理，没有独立的专属 tick 机制；功能差异主要来自阵类型和 JSON 配方。
5. 远古创造配方能够无输入产出命令方块，属于明显的开发/平衡占位内容。
6. 规划文档中的污染世界、引物、灵珠、宝珠、完整能源科技树等，不能据此认定已在当前代码中实现。

## 6. 推荐阅读路线

先理解阵的等级与类型，再学习单体阵加工；随后阅读阵总线与 IO，最后处理网格、数据包和兼容展示。遇到教程与游戏表现不一致时，应先核对当前资源包是否被其他数据包覆盖，再核对对应阵类型与输入区域，而不是套用规划文档中的旧流程。
