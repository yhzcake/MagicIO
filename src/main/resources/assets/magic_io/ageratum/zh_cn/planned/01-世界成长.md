# 世界与成长路线

> [!CAUTION]
> **本章全部属于规划内容，尚未实现。** 文中描述的是目标玩法，不代表当前构建已经存在对应维度、资源、物品、方块、配方或交互。可运行内容请以 `../current/` 的现状文档和源码为准。

## 1. 设计目标

MagicIO 计划提供一条从末世手工求生到元素终局的完整科技路线。成长的核心不是直接复制原版采矿流程，而是让玩家先从污染物中分离资源，再逐步发现元素、建立法阵、接入供能、完成自动化，最终获得对概率、空间、时间和物质的控制能力。

规划中的核心循环是：

1. 从环境中取得低纯度、强随机的基础资源。
2. 使用手工工具与粘土炉完成最早期加工。
3. 发现滑石并绘制首个法阵。
4. 通过元素阵提升加工种类、效率和资源纯度。
5. 建立阵能网络、存储与物流，减少人工操作。
6. 通过复合元素消除随机，构建确定性生产线。
7. 进入高阶复合法阵与自治网络阶段。

## 2. 世界入口

### 2.1 污染世界预设

污染世界计划作为可选初始世界：整体寒冷、天空笼罩灰黄色阴霾、水体受污染，并取消常规矿物生成。其目的不是单纯提高生存难度，而是从世界规则上保证玩家必须使用 MagicIO 的资源分离体系。

| 世界特征 | 规划表现 | 对成长的影响 |
| --- | --- | --- |
| 群系温度 | 约为 -2 | 强化寒冷末世氛围 |
| 常规矿物 | 不生成 | 阻断原版下矿捷径 |
| 污染水体 | 不可直接饮用且不冻结 | 强制学习净水 |
| 地表资源 | 污染泥土、焦木残骸等 | 支撑 LV-0 起步 |
| 视觉基调 | 深灰、暗褐与雾霾 | 明确世界主题 |

### 2.2 正常主世界

普通世界预设计划保留原版资源结构，仅额外生成滑石矿。污染世界玩家在中后期可借助空间相关机制进入正常世界。这样既保留常规整合包兼容路线，也允许专门围绕末世预设构建挑战玩法。

## 3. 阶段总览

| 阶段 | 等级范围 | 核心问题 | 关键突破 |
| --- | --- | --- | --- |
| 末世求生 | LV-0 | 如何得到水、泥土、火与工具 | 粘土炉、石刃、小型筛子阵 |
| 法阵启蒙 | LV-1～LV-2 | 如何从污染资源中取得金属 | 滑石、筛取金属、元素引物 |
| 法阵供能 | MV～HV | 如何让法阵持续、高效运行 | 阵能、稳定阵、升级模块 |
| 高阶时代 | HV～EV | 如何扩展产线吞吐量 | 存储、并行、过滤与频道 |
| 消除随机 | EV～IV | 如何精确控制产物 | 混沌阵与确定性配方 |
| 元素终局 | IV～MAX | 如何让网络自治并操控世界 | 描述、能量、意识、创造 |

## 4. 成长门槛

每一级成长都应由可观察、可验证的能力变化驱动，而不是仅替换材料名称：

- LV-0 的门槛是取得滑石并完成首个阵纹。
- LV-1 的门槛是从随机金属中凑出可用合金镐。
- LV-2 的门槛是完成基础元素发现和引物提纯。
- MV 的门槛是获得稳定引物并让法阵接入阵能。
- HV 的门槛是形成批量处理和初步自动输入输出。
- EV 的门槛是建立存储、频道物流与复合元素阵。
- IV 的门槛是把概率生产转换为确定性生产。
- MAX 的门槛是完成高阶复合元素并建立自治网络。

## 5. 路线约束

- 污染世界不能通过常规矿脉绕过资源分离阶段。
- 关键随机产物需要保底或可积累机制，避免玩家长期无法取得 ZA-27 等门槛材料。
- 高等级法阵应向下兼容低等级配方，但提速与能耗必须保持平衡。
- 自动化应逐级开放：手动、半自动、定向自动、网络自动、自治。
- 跨维度与物质创造属于终局能力，不应提前破坏资源压力。
