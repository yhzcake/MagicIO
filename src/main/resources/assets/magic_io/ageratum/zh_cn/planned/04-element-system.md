# 元素体系

> [!CAUTION]
> **本章全部属于规划内容，尚未实现。** 元素发现关系、加工能力和终局效果均可能在正式实现与平衡阶段调整。

## 1. 元素设计原则

元素不是单纯的配方分类，而是对加工机制的抽象。每种元素负责一类物理或逻辑变化，组合元素则负责更高层的流程、概率与信息控制。

## 2. 八种基础元素

| 元素 | 操控范畴 | 代表能力 | 机器类比 |
| --- | --- | --- | --- |
| 土 | 无机固体 | 筛选、离心、压榨、沉降 | 筛选机、压缩机 |
| 水 | 流体 | 净化、输送、溶解、蒸馏 | 水泵、精炼机 |
| 火 | 内能与热 | 加热、冶炼、热处理 | 熔炉、感应炉 |
| 风 | 机械能 | 粉碎、研磨、输送、真空 | 磨粉机、管道 |
| 木 | 有机物 | 培育、发酵、堆肥、提炼 | 培养室、发酵罐 |
| 冰 | 物态变化 | 制冷、冷凝、液化、温控 | 冷冻机 |
| 金 | 化学与冶金 | 提纯、合金、置换、催化 | 反应釜、合金炉 |
| 雷 | 电磁 | 发电、电解、电镀、磁化 | 发电机、磁化机 |

## 3. 初始引物

计划中的最早期引物包括：木炭粉作为火引，粘土粒作为土引，净化水作为水引，空手状态作为风引。引物负责把玩家可理解的材料与抽象元素建立联系。

“空手”不是物品，因此配方与交互 API 需要将其表达为上下文条件，不能伪造一个不可见物品。其他引物则应明确是否消耗、是否有容器返还，以及自动化设备如何提供。

## 4. 基础发现链

```text
土 + 水 → 木
水 + 风 → 冰
火 + 土 → 金
风 + 火 → 雷
```

这条发现链让玩家先掌握四种直观元素，再通过组合理解复杂加工。发现过程应要求两个法阵达到指定状态、处于有效结构关系并完成一次实验，而不是仅在工作台合成新物品。

## 5. 四种复合元素

| 元素 | 组合 | 规划能力 |
| --- | --- | --- |
| 秩序 | 木＋金 | 条件分流、顺序执行、负载均衡、配方编排 |
| 混沌 | 冰＋雷 | 概率增强、概率锁定、确定性转化 |
| 空间 | 冰＋木 | 远程传输、空间扩容、跨维度连接 |
| 时间 | 金＋雷 | 加速、减速、暂停、规划执行 |

这些能力会改变整个生产系统，因此必须设置等级、阵能和网络规模门槛。例如时间加速不能无限递归作用于另一时间阵；空间传输必须处理目标区块未加载和跨维度权限问题。

## 6. 高阶元素

| 元素 | 组合条件 | 定位 |
| --- | --- | --- |
| 描述 | 秩序＋混沌 | 读取与修改物品数据、保存模式 |
| 能量 | 空间＋时间 | AE/FE 转换、无线传能、能源质量提升 |
| 意识 | 雷＋土＋能量 | 经验、灵魂、生物探测与绑定 |
| 创造 | 描述＋能量＋意识 | 从能量生成物质并触及规则层能力 |

高阶能力需要严格限定数据白名单。描述阵若可任意写入组件或 NBT，会导致复制、越权物品和跨模组崩溃；创造阵也应使用显式注册的物质成本，而不是自动为所有物品估值。

## 7. 引物等级

| 引物 | 对应阶段 | 作用 |
| --- | --- | --- |
| 基础引物 | LV | 激活基础元素 |
| 提纯引物 | LV-2 | 支持稳定加工实验 |
| 稳定引物 | MV | 将法阵升至稳定级 |
| 强化引物 | HV | 解锁批量与更高容量 |
| 充盈引物 | EV | 解锁全自动与复合元素 |
| 古朴引物 | IV | 解锁确定性和复杂编排 |

引物批量生产属于中后期自动化目标。每一级引物都应依赖前一级产线，保持科技树闭环，不能让高阶材料通过普通战利品轻易绕过。

## 8. 灵珠与宝珠

EV 阶段计划为八种基础元素提供灵珠，用作对应法阵的便携强化核心；IV 阶段为秩序、混沌、空间和时间提供宝珠，承担网络级能力。它们应是功能载体而非单纯数值材料，并具有清晰的装入、取出、绑定和复制限制。

## 9. 兼容原则

- 元素配方优先使用物品与流体标签，减少对具体模组 ID 的硬编码。
- 能源转换必须声明转换比、损耗与每刻上限。
- 数据修改只开放安全字段，禁止任意复制外部模组内部状态。
- 生物与灵魂能力应尊重黑名单、Boss 判定和服务器权限。
- 时间加速应通过受控接口推进，不应无条件增加随机刻或直接重复方块实体刻。
